# My little agent

Эксперимент с запуском LLM локально на телефоне.  
В качестве LLM используется [Qwen2.5-Coder-1.5B-Instruct](https://huggingface.co/litert-community/Qwen2.5-Coder-1.5B-Instruct/tree/main).  
Фреймворк для интеграции LiteRT-LM.
Телефон, на котором тестирую, Honor Magic 6 Pro:
* **Процессор**: Snapdragon 8 Gen 3
* **Оперативная память**: 12 Гб
* **GPU**: Adreno 750  

В данной итерации модель висит в ассетах модуля :core:llm и копируется в файловую систему. 
В дальнейшем поведение будет переделано под скачивание, либо подгрузку через adb в файловую систему.
